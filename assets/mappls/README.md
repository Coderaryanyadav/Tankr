# Mappls Native Map SDK License Files

Place your licensed native Mappls map configuration and offline license files in this directory:
- `android/` -> `*.a.conf`, `*.a.olf`
- `ios/` -> `*.i.conf`, `*.i.olf`

> **Security Notice**: Native `.conf` and `.olf` license files contain proprietary credentials and are intentionally ignored by `.gitignore`. Do not commit production license files to source control.
